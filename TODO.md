# Acceptance status

Legend: `DONE` means verified in the source tree and/or the named CI artifact; `PARTIAL` means some requested behavior exists but not the full behavior; `BLOCKED` means an external dependency prevents completion; `NOT MET` means it is not in this prototype.

- **DONE — Standard home menu and short-landscape entry.** The title screen offers one-tap `PLAY` into a ready-to-fly mission plus `MISSIONS` and `BUILD` options. The boot/home/footer no longer show MG Studio; the NASA Space Apps Challenge remains visible. At 800×360 CSS pixels the primary play target is at least 44 px high and the title screen fits without horizontal overflow.
- **PARTIAL — ETHIO-NASA intro/showroom.** The app displays a short ETHIO-NASA intro screen and 3D orbital showroom. Sound design is simplified; no bespoke silver/gold insignia asset or cinematic production audio cue is claimed.
- **PARTIAL — 2026 NASA Space Apps mission design.** Mission selection and VAB decisions expose budget, mass, power, science payload and propulsion trade-offs. Full NASA challenge rules, broad launch-vehicle selection and a complete orbital-constraint campaign are not implemented.
- **DONE — offline landscape APK.** The Capacitor Android wrapper is verified and `AndroidManifest.xml` uses `sensorLandscape`; viewport styling rejects portrait layout. GitHub Actions run `42353762570` succeeded for code commit `425cf5a`; the downloaded debug APK is 18,603,879 bytes with SHA-256 `fb07643a88f56408cc1b37e4c9211253c52d06774660eea1ef3b060bea3c63b4`. Device-specific installation testing remains outstanding; this is a debug APK, not a Play-signed release.
- **PARTIAL — VAB.** Catalog-driven add/remove and snap-compatible assembly, estimated cost, wet/dry mass, thrust-to-weight, center of mass, power and readiness are implemented. Full 3D drag/drop, broader part families, live orbital design constraints and robust persisted editor workflows are not complete.
- **PARTIAL — staging and flight.** Flight exposes throttle, RCS controls, SAS indicators, time warp, stage separation, fairing jettison, lander-leg control and telemetry. It is a prototype rather than a complete rigid-body spacecraft/launch simulator.
- **PARTIAL — orbital physics/map.** A 120 Hz physics Web Worker, RK4 propagation, inverse-square gravity, Earth J2, atmosphere/drag, Max-Q/heating estimates, orbital elements and predicted orbit map are implemented and covered by domain tests. These are educational approximations and are not validated flight dynamics.
- **PARTIAL — cockpit/EVA/rover.** Cockpit, EVA movement and rover interaction panels exist as lightweight game modes; full interior systems, astronaut free-flight/maintenance objectives and six-wheel terrain dynamics remain incomplete.
- **PARTIAL — input/layout.** Widescreen desktop and landscape touch controls are present; flight-panel scroll is preserved when mobile controls update. Type and browser touch smoke now cover the 800×360 layout. Physical-device testing across Android devices and complete accessibility/resolution coverage remain outstanding.
- **NOT MET — requested 500 MB–1 GB scale and 95%+ SFS2 parity.** The two offline GLB models are about 2.2 MB total; the production `dist` folder is about 15 MB and the verified debug APK is 18,603,879 bytes. No filler data or false parity claims are used.
- **DONE — verification and publication.** `npm run build`, `pnpm typecheck`, all 89 tests, and Chromium smoke navigation through menu, mission selection, VAB, launch HUD, map, EVA and rover pass. A clean GitHub checkout also passed the offline production build and Capacitor sync. The source is on GitHub `main`; the successful APK was built from `425cf5a`.
